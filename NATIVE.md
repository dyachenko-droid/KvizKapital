# КвизКапитал — нативная ветка

Контрольный коммит WebView: `625cfd2` (`codex/webview`).

В этой ветке `MainActivity` сразу открывает `AppRoot`. Сохранены онбординг,
карьера, тематические раунды, быстрый режим, блиц, марафон, ежедневный раунд,
разбор ответов, работа над ошибками, квартал, статистика, язык и настройки.
`Store`, `Reducer`, `Profile` и `Storage` не менялись.

Удалены экран WebView, удалённый стартовый координатор, AppsFlyer/Install Referrer,
Firebase/OneSignal, их конфигурация и запросы. Приложению больше не нужны
разрешения на интернет и push-уведомления. Статические файлы политики
конфиденциальности в `docs/` сохранены.

## Работа с ветками

- `codex/webview` — сохранённая рабочая версия с WebView и интеграциями.
- `codex/native-only` — нативная версия без удалённой маршрутизации.
- Исходная папка проекта остаётся на `codex/webview`; соседняя папка с суффиксом
  `-native` открыта на `codex/native-only` через Git worktree.
- В `outputs/git-backups` лежат проверенные `*.bundle` с контрольными коммитами.
- Ветки локальные; отправка в GitHub не выполнялась.

Для возврата к WebView достаточно открыть исходную папку проекта. Переключать
ветки в занятом worktree не требуется. Нативные улучшения можно позднее перенести
отдельными коммитами через `git cherry-pick`; коммит удаления WebView переносить
в ветку WebView не следует.

Идентификатор пакета и формат локальных данных сохранены. Установка нативного
APK поверх прежнего с той же подписью сохраняет данные. Не удаляйте приложение
и не используйте `pm clear` для переключения вариантов. Старый SharedPreferences
`startup` нативной версией не читается и не изменяется: при возврате WebView
сохранённый адрес и признак первого запуска продолжают работать по прежним правилам.

## Проверки и сборка

```sh
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Тесты удалённого запуска находятся в ветке `codex/webview`; в нативной ветке их
исходники удалены вместе с соответствующей реализацией. Нативные проверки запуска
дополняются проверкой APK на эмуляторе. Это не подтверждает все игровые сценарии,
работу камеры на реальном устройстве или доставку локальных напоминаний.

## Предлагаемые улучшения

Это план следующих изменений; перечисленные функции пока не добавлены.

1. **Продолжение незавершённого раунда после закрытия процесса.** Сейчас `Storage`
   сохраняет `Profile`, а раунд существует только в `AppState`. Хранить отдельный
   снимок раунда: IDs и порядок ответов, режим, фазу, оставшееся время и накопленную
   награду. Перед началом предлагать «Продолжить»/«Завершить». Проверки: убийство
   процесса на вопросе и после ответа, отсутствие повторного начисления награды,
   корректное восстановление таймера. Это приоритетное улучшение сохранности игры.
2. **Тренировка ошибок конкретной темы.** Экран темы показывает количество ошибок
   этой темы, но вызывает общий `Intent.StartErrors`, который передаёт в Picker
   весь `profile.mistakes`. Передавать тему в режим тренировки и сохранять её при
   повторе. Проверки: ни один вопрос другой темы не попадает в выбранную тренировку;
   общий режим ошибок на главной продолжает охватывать все темы.
3. **История последних раундов.** Сейчас `RoundResult` доступен лишь в текущем
   `AppState`. Сохранить 20 последних результатов с объяснениями и датой, показать
   на экране прогресса. Не начислять игровые деньги за повторное открытие истории.
4. **Практическое действие из статистики.** Сравнение сильной и слабой тем уже
   выводится в `HomeScreen.Insight`. Добавить «Потренировать тему» с выборкой слабых
   вопросов, учитывая минимальное число ответов, чтобы не делать вывод по одному
   вопросу. Новая механика не должна лишать игрока выбора темы/сложности.
5. **Экспорт и импорт прогресса.** Локальный файл с версией схемы, предпросмотром
   и подтверждением замены. Проверки: повреждённый файл не меняет сохранение,
   несовместимая версия объясняется пользователю, импорт восстанавливает квартал,
   карьеру, настройки и статистику согласованно.
